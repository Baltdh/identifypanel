# Perfis DTBO

Sem binários nesta primeira entrega. Importar os arquivos originais da release ROCKNIX:
https://github.com/stolen/rnix/releases/tag/panel_overlays

Para cada arquivo, registrar nome de origem, tamanho, SHA-256, metadados extraídos por dtc e resultado físico. Não inferir compatibilidade R36H pelo nome r36s-panelX.

O relato de que Panel 4 funciona no DarkOS é apenas pista para priorizar o teste; não prova equivalência com r36s-panel4 no ROCKNIX.
